3. Analysis (The GIL):
Based on your results, why did Multithreading fail to make the code run faster? Why is Multiprocessing a better choice for CPU-bound tasks (like Machine Learning data augmentation) in Python?
:Multithreading did not make the program significantly faster
because Python has a Global Interpreter Lock (GIL), which
prevents multiple threads from executing Python bytecode
simultaneously.

Multiprocessing is better for CPU-bound tasks because each
process has its own memory space and its own GIL. Therefore,
multiple processes can run on different CPU cores at the same
time and achieve true parallelism.
